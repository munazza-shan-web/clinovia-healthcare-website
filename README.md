# Clinovia Healthcare SaaS Website

A modern, clean, and responsive healthcare SaaS website designed for a fictional digital healthcare platform.

Clinovia demonstrates how a healthcare technology company can present its services, features, solutions, and platform benefits through a professional web interface.

## Live Demo

[View Clinovia Live](https://munazza-shan-web.github.io/clinovia-healthcare-website/)

## Features

* Modern healthcare-focused design
* Responsive layout for desktop, tablet, and mobile
* Professional navigation and page structure
* Healthcare SaaS hero section
* Services and platform features
* Solutions section
* Testimonials
* Call-to-action sections
* Contact section
* Clean typography and spacing
* Mobile-friendly design

## Technologies

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
